## 🛠️ Tech Stack & Architecture

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4 + Dark Industrial Theme (`#050505` & `#BE1522`)
- **Key Modules**:
  - **Hero**: Clean high-contrast typography, live status indicator, and dynamic CTA layout.
  - **Services**: 3-column responsive grid focusing on core development & design capabilities.
  - **TechStrip**: Infinite marquee loop (45s) with dual 25% gradient fade masks and optical scale normalization.
  - **About**: Professional profile breakdown & quantitative metrics.
- **Language**: TypeScript

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🔨 Build & Production

Build for production:

```bash
npm run build
npm start
```
